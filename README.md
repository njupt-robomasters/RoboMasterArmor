# RoboMasterArmor

自制 RoboMaster 装甲板。

这是一个装在机器人装甲板上的控制器：负责检测被击打并上报到裁判系统，同时用灯条显示当前的阵营颜色和系统状态。三块板子烧录同一份固件，用手机配网决定哪一块连网，另外两块跟随它。

## 它做什么

- **击打检测**：读取装甲板上的压电/振动传感器，判定有效击打。
- **击打上报**：把击打事件通过 Wi-Fi 发给 RoboMaster 裁判系统。
- **灯光显示**：用 WS2812 灯条显示阵营颜色、配网状态、登录状态和阵亡状态。
- **阵营切换**：短按按键在红方和蓝方之间切换。
- **手机配网**：长按按键开热点，手机浏览器填写 Wi-Fi 和机器人编号。
- **三板同步**：一块主板上网登录，另外两块通过 CAN 跟随，三块灯色始终一致。

## 硬件

- 主控：ESP32-C3
- 开发框架：Arduino（PlatformIO）
- 程序结构：单线程 `loop()` 轮询，不使用 FreeRTOS

| 功能 | 引脚 |
| --- | --- |
| 击打传感器 | GPIO0（ADC1 CH0）|
| CAN RX | GPIO6 |
| CAN TX | GPIO7 |
| 按键 | GPIO9（内部上拉，按下为低）|
| WS2812 灯条 | GPIO10，22 颗 |

CAN 速率 1 Mbit/s，串口为 ESP32-C3 原生 USB CDC，115200。

## 使用流程

1. **上电**：如果之前配过网，板子会自动联网并按已保存的阵营亮灯；没配过网则停在离线状态。
2. **进入配网**：长按按键 1 秒，这块板成为配网主机，三块板一起黄灯闪烁。
3. **手机连接**：连上热点 `RM_<MAC地址>`（密码 `12345678`），浏览器打开 `http://192.168.4.1/`。
4. **填写保存**：填 Wi-Fi 名称、密码和机器人编号，点保存。三块板转为黄灯常亮。
5. **联网登录**：主板连接 Wi-Fi 并登录裁判系统，成功后三块板显示阵营颜色。
6. **切换阵营**：短按按键，红蓝互换（机器人编号加减 100，例如 `3 <-> 103`）。
7. **退出**：长按按键退出到配网模式。

## 配置持久化

Wi-Fi 名称、密码、机器人编号和阵营保存在芯片 NVS 中，**掉电不丢失**：

- 断电时处于**在线**状态 → 上电自动进入联网流程，恢复上次的 Wi-Fi 和阵营。
- 断电时处于**离线**状态 → 上电保持离线，需要长按重新配网。

因此配好网之后不需要每次上电都重新配网。如果要换网络或换阵营，长按进入配网重新保存即可。

## 三块板如何协同

配网并保存的那块板成为主机，另外两块成为从机。

- 主机连接 Wi-Fi 和裁判系统，是唯一的状态广播者。
- 从机不联网，只通过 CAN 跟随主机。
- 主机每 50ms 广播一次公共状态（配网/联网/登录/在线/阵亡、阵营颜色、闪烁相位）。
- 在线状态下任意一块板长按，可以成为配网主机，原主机让位。
- 从机的按键请求和击打事件都发给主机，由主机统一处理。

## CAN 协议

所有内部报文统一使用标准 ID `0x000`，固定 DLC=8，`data[0]=0xA0`。

```text
byte 0：固定 0xA0
byte 1：模式  0离线 1配网 2连接Wi-Fi 3裁判登录中 4在线 5阵亡
byte 2：标志  bit0配网 bit1黄灯亮相 bit2发送者为主机 bit3状态变化 bit4主机接管
byte 3：阵营  0红 1蓝
byte 4：LED 亮度
byte 5：事件  0状态 1切换阵营 2主机接管 3退出 4击打 5确认
byte 6：状态版本号 uint8_t
byte 7：事件参数
```

主机周期广播状态，从机只应用较新的版本。从机的按键请求和击打事件通过 pending 标志重试发送，主机处理后用新状态或确认事件清除。

## 灯光状态

| 状态 | 显示 |
| --- | --- |
| 离线 / 在线 | 红或蓝阵营色常亮 |
| 配网 | 黄灯闪烁 |
| 保存后联网 | 黄灯常亮 |
| 裁判登录中 | 紫灯常亮 |
| 阵亡 | 灯灭 |
| 被击打 | 灭 50ms 后恢复 |

## 常用参数

需要调整的参数集中在 `include/config.hpp`：

```text
HIT_THRESHOLD                 击打阈值（默认 2000）
HIT_COOLDOWN_MS               击打冷却（默认 50ms）
LED_BRIGHTNESS                WS2812 亮度 0~255
LONG_PRESS_MS                 长按判定时间（默认 1000ms）
CAN_BITRATE                   CAN 速率（默认 1 Mbit/s）
PROVISIONING_WIFI_PREFIX      配网热点名称前缀（默认 RM_）
PROVISIONING_WIFI_PASSWORD    配网热点密码
PROVISIONING_BLINK_MS         配网黄灯闪烁周期
TEAM_SWITCH_PURPLE_MIN_MS     切换阵营后紫灯最短保持时间
REFEREE_SERVER_IP             裁判系统服务器地址
KEY_PIN / WS2812_PIN / CAN_RX / CAN_TX    引脚定义
```

调试日志开关：`CAN_DEBUG`、`HIT_DEBUG`、`REFEREE_HP_DEBUG`，正式使用前建议关闭。

## 注意事项

- 目标热点必须是 2.4GHz（ESP32-C3 不支持 5GHz）。
- 修改机器人编号或 Wi-Fi 后需要重新长按配网并保存。
